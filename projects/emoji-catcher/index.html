Emoji Catcher

Catch as many smiling faces as you can in a 30-second round.

Caught: 0

Time left: 30 seconds

Total faces: 0

Missed: 0

Wrong clicks: 0

Catch the smiling face before it moves. Stop the round to change the pace, then start a new round. A wrong click counts as a miss and immediately moves the face. Total faces includes the current face; any face left at the end counts as missed. Keyboard: focus the board, move with arrow keys, and press Enter or Space to catch it.

The game starts only when you choose Start round. Scores are not saved. The round ends using elapsed time, including time in background tabs.
