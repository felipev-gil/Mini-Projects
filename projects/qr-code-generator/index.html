QR Code Generator

Create a QR code for short text or a URL entirely on your device.

Up to 250 UTF-8 bytes. Shorter text makes the code easier to scan.

Codes are generated locally using the bundled QRCode.js 1.0.0 library (MIT). Text is never sent to an external service or saved. The code uses black on white with a quiet border; scan the downloaded image to verify its contents before sharing.
