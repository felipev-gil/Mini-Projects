## Avatar artwork

Avatar Generator uses the DiceBear HTTP image API. The app does not modify returned artwork.

- [Lorelei](https://www.dicebear.com/styles/lorelei/): artwork by Lisa Wischofsky, CC0 1.0.
- [Pixel Art](https://www.dicebear.com/styles/pixel-art/): artwork by DiceBear, CC0 1.0.
- [Bottts](https://www.dicebear.com/styles/bottts/): artwork by Pablo Stanley, under the [Bottts usage terms](https://bottts.com/).

The style pages provide author links, license details, and upstream sources.

## API content

- [ExchangeRate-API](https://www.exchangerate-api.com/): exchange rates.
- [TheMealDB](https://www.themealdb.com/api.php): meal descriptions, recipes, and images. This educational demo uses test key 1; app-store distribution has different requirements.
- [GitHub REST API](https://docs.github.com/en/rest): public profile and repository information. Repository licenses remain with their owners.
- [PokéAPI](https://pokeapi.co/): Pokémon reference data and sprite links. Pokémon names and artwork belong to their respective rights holders; this collection is unofficial.

Third-party availability and content can change independently of this repository. Provider responses are rendered as text, and external links accept HTTPS URLs only.
