## External blocker: Country Lookup

On September 12, 2026, a browser fetch to `https://restcountries.com/v3.1/name/Colombia` failed with `TypeError: Failed to fetch`; an HTTP response was not accessible to JavaScript. That observation alone does not distinguish CORS from a network/service failure. The provider's [current documentation](https://restcountries.com/) advertises an authenticated v5 API with a different response shape. The original unauthenticated v3.1 integration cannot presently be verified live.

The page is integrated and tested with controlled success, no-results, HTTP 429 and network responses. The catalog and page disclose the live blocker. No private key, demo credential, backend or silent substitute dataset was added. To restore live operation, verify a suitable public browser-accessible country service, adapt its response fields, and repeat the tests. Remove the catalog status and page notice only after that succeeds.

## Foundation findings

The home page had duplicate `favorites` IDs and never rendered curated favorites. Header theme initialization depended on a page-owned `themeButton`; the footer year ran before its fragment loaded. Asset references disagreed with the `Assets` directory and `Logo.png` casing. Shared element/class selectors affected project content, and responsive grid rules targeted flex layouts. These were replaced with a self-contained shell, opt-in project styles and actual catalog grids.

The old `currency-convertor/index.html` remains as a relative redirect to `currency-converter/index.html`, preserving historical links. Original PNG/ICO assets remain; the active logo and small favicon use purpose-made SVG files with exact-case paths.
